# 常见 skill 模式词典

> 小石识别节点/结构时的统一参照。看到下面这些「套路」，用统一叫法命名，别每次重新发明术语。
> 这就是「积木拼大楼」里的那几种标准积木。

## 1. 主入口 / 总开关
- **长什么样**：一个 `SKILL.md` / `router.md` / `CLAUDE.md` / `AGENTS.md`，带 frontmatter（name/description），是整套技能的起点。
- **怎么识别**：文件名在 `SKILL.md > skill.json > router.md > CLAUDE.md > AGENTS.md > README` 这个优先级里，且常被其它文件引用。
- **典型措辞**：「先读取」「唯一入口」「开始任何工作前」。

## 2. 路由 / 分发（Router）
- **长什么样**：主入口里一段「根据用户意图分到不同分支/子流程」的逻辑。
- **怎么识别**：出现「典型信号」「分支映射」「如果…进入…」「意图归入且只能归入一个」。
- **本质**：用条件判断把一个大 skill 拆成多个子流程，避免一个文件啥都管。

## 3. 阶段 / Phase
- **长什么样**：把流程切成有序的几段（R→A→B→C、Phase1/2/3），每段有产物、有门禁。
- **怎么识别**：「阶段判断」「阶段文件」「进入下一阶段」「每阶段输出后」。
- **本质**：把复杂任务分解成可检查的里程碑。

## 4. 门禁 / 约束（Gate / Constraint）
- **长什么样**：「必须同时满足以下条件才能…」「禁止…」「未确认不得…」。
- **怎么识别**：清单式前置条件、禁止项、`❗` 标记、「不得」「必须」。
- **本质**：用硬性检查防止跳步或产出不合格。

## 5. 降级链（Fallback chain）
- **长什么样**：「优先用 A，不行用 B，再不行用 C」的多级兜底。
- **怎么识别**：「降级」「fallback」「优先…否则…」「offline / 离线模式」。
- **本质**：在外部依赖/环境不满足时仍能产出。**小石挑刺时重点看这里**：降级是否覆盖「依赖根本不存在」的情况。

## 6. 单一真相源 + 平台适配（Source of truth + adapters）
- **长什么样**：核心逻辑只在一处（`src/` 或 `harness-core/`），各平台目录（`.claude/ .codex/ .cursor/`）只做薄入口。
- **怎么识别**：「核心规则只能维护在」「平台目录只做适配」「不要复制完整流程」，或一个 CLI 安装器按 `--ai <platform>` 生成入口。
- **本质**：解决多端复用，改一处全平台生效。**这是跨平台 skill 的标志性积木。**

## 7. 脚本 + 数据引擎（Script + data engine）
- **长什么样**：真正干活的是脚本（`*.py`）+ 数据文件（CSV/JSON），提示词只负责触发与解释。
- **怎么识别**：`scripts/` 目录、`search.py`、CSV/JSON 数据库、确定性命令调用。
- **本质**：把发挥空间收进确定性代码 → 输出稳定、可测试、省 token。

## 8. 两种激活模式（Auto-skill vs Slash-command）
- **长什么样**：支持自动激活的平台靠 description 触发；只认命令的平台用 `/skill-name`。
- **怎么识别**：「Skill Mode（auto-activate）」「Workflow Mode（slash command）」。
- **本质**：适配不同平台的能力差异。

## 9. 渐进式披露（Progressive disclosure）
- **长什么样**：主入口保持精简，细节拆到 `reference/*.md`，按需读取。
- **怎么识别**：主入口里「详见 reference/xxx.md」「需要时读取」。
- **本质**：控制上下文体积，主流程不被细节淹没。

## 10. 模板产物（Template output）
- **长什么样**：固定的 N 章节 / N 字段产物（如 `design.md` 九章节、报告模板）。
- **怎么识别**：「按 N 章节模板生成」「输出格式」「这个模板」。
- **本质**：用固定结构保证产物一致。**小石必须逐项展开这些章节/字段。**
